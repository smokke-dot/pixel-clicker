# Пиксель — кликер (Telegram Mini App)

Кликер в пиксель-арт стиле с **тремя способами заработка и билдами**, **деревом
вечных баффов за престиж**, **уникальными скинами** (не перекраска — разные
персонажи) и **глобальным топом игроков**.

## Файлы

- `index.html` — игра (фронтенд), отдаётся сервером.
- `server.js` — бэкенд: авторизация, топ, продажа скинов за Stars. **Без зависимостей** (Node 18+).
- `package.json` — только для `npm start`.
- `data.json` — создаётся автоматически, хранит игроков и покупки.
- `sw.js` + `manifest.webmanifest` + `icon-*.png` — PWA-оффлайн (кэш после первого захода).

## Как работает

### Три канала дохода → три билда
- **👆 Клик** — тапай слайма. Прокачивай силу клика, крит-шанс, крит-урон, множитель.
- **🤖 Автодоход** — монеты в секунду. Авто-боты, фермы, лаборатории, авто-множитель.
- **🍀 Удача** — периодически появляется **золотая монета**. Тапни её — получишь куш
  с бонусом +25%, а не успел — она соберётся сама по истечении времени. С апгрейдом
  «Авто-сборщик» монеты зачисляются автоматически, без тапов.

Можно качать всё сразу или уйти в один билд — работает и то, и другое.

### Дерево баффов (престиж)
Сброс прогресса → получаешь **осколки** (💠), которые тратишь в «Дереве баффов»
на **вечные усиления**: ветки клика, автодохода, удачи и глобальная. В каждой ветке
3 уровня, узлы открываются по порядку (1 → 2 → 3). Усиления не пропадают после
следующего сброса — это и есть «постоянное развитие».

### Скины
20 уникальных персонажей (слайм, котёнок, призрак, грибок, робот, снеговик,
пришелец, панда, лиса, пингвин, тыква, кактус, единорог, цыплёнок, кролик,
золотой слиток, неоновый куб, радужная звезда, дракон, кибер-кот) — это
**разные спрайты**, а не перекраски. У каждого свой бонус. Открываются:
**за монеты**, **за престиж** и **за Stars**.

### Топ
Четыре рейтинга: 💰 текущие монеты, ⚡ монеты в секунду, 💠 осколки (набранные за
всю игру) и 🔄 количество престижей. Авторизация через Telegram `initData` (HMAC).

### Ежедневная награда
За ежедневный вход даётся награда монетами (растёт с прогрессом). Заходи несколько
дней подряд — серия увеличивает награду (до ×2.5 на 7-й день).

### Настройки
Вкладка «⚙️»: звук, вибрация и эффекты (частицы/всплывающие числа) — включаются,
выключаются и сохраняются между сессиями.

### Оффлайн
Игра — PWA: после первого открытия файлы кэшируются (Service Worker), поэтому
работает без сети. Топ и покупка скинов за звёзды требуют интернет и запущенный
сервер, всё остальное — оффлайн.

### Сброс прогресса
Сбросить прогресс «просто так» нельзя — сброс происходит только через **престиж**,
который обнуляет монеты и улучшения, но даёт 💠 осколки навсегда (тратятся в дереве).

## Запуск

Нужен **Node.js 18+** и токен бота от [@BotFather](https://t.me/BotFather).

```bash
# Windows (PowerShell):
$env:BOT_TOKEN="123456:ABC-DEF..."
node server.js

# Linux/macOS:
BOT_TOKEN=123456:ABC-DEF... node server.js
```

Открой `http://localhost:3000`. Без `BOT_TOKEN` игра работает локально,
но топ и скины за звёзды отключены.

## Подключение к Telegram

1. Создай бота в [@BotFather](https://t.me/BotFather): `/newbot`, сохрани токен.
2. Опубликуй проект на HTTPS-хостинге с Node (Render, Railway, Fly.io, Glitch, VPS).
   `index.html` и `server.js` в одной папке, запуск — `node server.js` (или `npm start`).
3. Укажи переменную окружения `BOT_TOKEN` на хостинге.
4. В @BotFather: `/newapp` → выбери бота → название → описание → фото →
   **URL мини-аппа = адрес твоего сервера** (например `https://mygame.onrender.com`).
5. Открой мини-апп. Оплата звёздами работает сразу: сервер слушает платежи через long-poll бота.

> Локальный тест на телефоне: `npx localtunnel --port 3000` (или `cloudflared`),
> а в `/newapp` дай URL, который выдаст туннель.

## Как устроена оплата звёздами

1. Игрок жмёт «⭐ 25» → фронт просит сервер создать счёт (`createInvoiceLink`, валюта `XTR`).
2. Игра открывает ссылку через `Telegram.WebApp.openInvoice`.
3. Бот отвечает на `pre_checkout_query` и фиксирует `successful_payment` → сервер
   навсегда записывает скин в профиль.
4. Игра опрашивает статус и открывает скин.

## Настройка баланса (все значения — в `index.html`, если не указано иное)

- Улучшения — массив `UPGRADES` (поля `base` — цена, `mult` — рост цены).
- Дерево баффов — массив `TREE` (цена в осколках: `base` + `mult`, эффект в `effect`).
- Престиж — константа `PRESTIGE_BASE` (сколько монет за ход даёт 1 осколок).
- Скины, спрайты и бонусы — массив `SKINS` (цена монетами — `coins`, звёздами — `price`, престижем — `prestige`).
- Цены звёзд — объект `PAID_SKINS` в `server.js` (держите `id` синхронными со `SKINS`).
